# learning

«магистерская» по интерфейсам к знанию и структурам знания.

## План обучения

Каждый сезон жёстко привязан к очередной версии S/R/O-системы:
извлечение квадрупелей `[subject, relation, object, domain]` → карты → DSL → тактильность.
Я не умею читать «только нужное» — иду от корки до корки, но по одному основному треку за сезон.

### Сезон 1 (10-12 недель): S/R/O + карты — JS + awk + Raskin/Norman/Pirolli

Фокус:
- 30 days of JavaScript (DOM, события, состояние, проекты) — скелет курса, в своём темпе
- awk: GNU Awk User's Guide + Effective AWK (паттерны, поля, массивы, пайплайны)
- Книги: 
	- Raskin (Humane Interface), 
	- Pirolli & Card (foraging/sensemaking)
	- Norman (Design of Everyday Things), 
	- Статьи:
		- 🔥 @li2025
		- 🔥 @pirolli2006
		- @li2026
		- @banaee2014
		- @gardenfors
		- @zhu2024

	Артефакт:
	- Система извлекает S/R/O из 10-20 текстов и строит карты (граф/дерево), базовое сравнение карт
	- Chrome-ext: выделяешь фразу на странице → помечаешь `[S, R, O, domain]` → side panel собирает карту
	- Интерфейс оценён по принципам: видимость, обратная связь, концептуальная модель (Норман), безрежимность/единый способ (Раскин), поддержка foraging/sensemaking (Pirolli)

	Критерии завершения:
	- пользуюсь системой 2-3 раза в неделю на реальных текстах
	- написан кейс «как я использую это для исследования»


### Сезон 2 (12-14 недель): DSL + глубина — SICP + Nand2Tetris + About Face

	Фокус:
	- SICP: главы 1-4 (процедуры, данные, интерпретаторы)
	- Nand2Tetris: ключевые проекты (логика, АЛУ, процессор, ассемблер, компилятор/VM) — связка «язык → исполнение»
	- About Face (Купер): goal-directed дизайн, персоны/сценарии
	- Статьи:
		- tversky2015

	Артефакт:
	- DSL запросов к картам («найти все relation между X и Y», «объединить карты по subject») + интерпретатор
	- Интерфейс переработан по About Face: явные цели, сценарии

Критерии завершения:
- объясню путь от NAND до исполнения DSL-команды
- DSL используется в реальных сессиях sensemaking

### Сезон 3 (10-12 недель): Тактильность — Physical Computing

Фокус:
- Makeability Lab Physical Computing: сенсоры/актуаторы, тактильные интерфейсы
- Arduino/ESP32: энкодеры, кнопки, дисплеи, связь с nodejs (UART/USB/MQTT)
- Статьи:
	- @kirsch1995

Артефакт:
- Тактильная панель для навигации по картам: энкодер/кнопки для перемещения по графу, переключения видов, вызов DSL-запросов
- Кейс «тактильный интерфейс для исследования»

Критерии завершения:
- панель используется 1-2 раза в неделю
- описан вклад тактильности в foraging/sensemaking (Pirolli)
